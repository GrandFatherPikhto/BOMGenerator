# План: вкладка «Все» в закупках (сводная таблица по включённым платам)

Продолжение плана [`add-purchase-table-filters.md`](plans/add-purchase-table-filters.md).

## Цель

Добавить на страницу «Закупки» переключатель **«По платам» / «Все»**:

- **По платам** — текущее поведение: селект платы, редактирование строк платы.
- **Все** — сводная таблица по всем платам, отмеченным «Включено» (исключая
  служебную «Докупить»), с теми же фильтрами, что и раньше
  ([`LineFiltersBar`](src/client/components/LineFiltersBar.jsx:1)).

Во вкладке «Все» строки группируются по **Value + Посадочное место + источник
закупки (выбранный товар)**:

- один компонент с одним товаром — одна строка, количество суммируется
  (`qty × Плат в изделии` по всем включённым платам);
- один компонент с разными товарами/продавцами — отдельные строки, каждая
  **подсвечивается** как сигнал «источники стоит объединить, чтобы сэкономить
  на доставке»;
- отдельная колонка **«Платы»** — список плат, где компонент задействован,
  каждое название — ссылка на закупку этой платы (вкладка «По платам»);
- строки, которые на платах помечены «Общие», в «Все» **не показываются**
  (они обслуживаются на вкладке «Общие закупки»).

Состояние страницы сохраняется в URL и переживает переходы между вкладками и
правки: `tab`, `board`, `page`, `size` и все фильтры.

## Модель агрегации

Ключ группы: `matchKey` строки (**Value + Посадочное место**) **+ `productId`**.

- `totalQty` = сумма `qty × board.count` по строкам группы.
- `byBoard` — та же сумма в разрезе имён плат (для подсказки/аналитики).
- `boards` — уникальные `{ id, name }` плат группы (для колонки «Платы»).
- `hasMultipleSources` — флаг на уровне компонента (`matchKey`): у него
  выбрано ≥ 2 различных непустых `productId`. Строки без товара группируются
  вместе, но сами не подсвечиваются.
- Редактируемые поля товара/упаковок/доставки/описания при различающихся
  значениях внутри группы показываются как «разные»; изменение применяется ко
  всем строкам группы.
- «Стоимость» считается только когда у группы выбран единый товар.

## Фильтр продавца

Селект «Продавец» переезжает из отдельной строки в
[`LineFiltersBar`](src/client/components/LineFiltersBar.jsx:1) — в один ряд с
value/footprint/количеством — и становится **фильтром строк**: выбранный
продавец оставляет только позиции, закупленные у него. При этом он продолжает
сужать список товаров в колонке «Товар».

Список продавцов строится из строк текущего представления, плюс пункт
«Все продавцы»:

- вкладка «По платам» — продавцы, реально используемые в данной плате;
- вкладка «Все» — продавцы, используемые по всем включённым платам;
- «Общие закупки» — продавцы, используемые в общих закупках.

Выбранный продавец входит в набор сохраняемых в URL фильтров.
